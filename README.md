# Movies

Kino plugin: films and series from TMDB, with video from PrimeSrc's servers (Voe, Filemoon, Streamtape and more) opened in Kino's hidden browser.

- Catalog: Home rows, genres, search, details and episodes, all from TMDB with a key sealed in the manifest (`TMDB_KEY`).
- Video: `resolve` lists PrimeSrc's servers and captures the video the host's own player requests. Needs the "hidden pages" permission.
- Install from this repository's default branch (the sealed key only opens there).
